## 🚀 How to Deploy to GitHub Pages

### Option 1: Using Git via Terminal / Command Prompt

1. Open PowerShell or Command Prompt in this folder:
   ```bash
   cd C:\Users\HP\Downloads\prothamsarker.github.io
   ```

2. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of GitHub Pages portfolio"
   git branch -M main
   ```

3. Create a new public repository on GitHub named:
   ```text
   prothamsarker.github.io
   ```
   *(Note: The repository name must be `<username>.github.io` for GitHub to serve it as your user page)*

4. Link the repository and push:
   ```bash
   git remote add origin https://github.com/prothamsarker/prothamsarker.github.io.git
   git push -u origin main
   ```

5. Go to your repository settings on GitHub:
   - Navigate to **Settings** > **Pages**
   - Under **Build and deployment > Source**, select **Deploy from a branch**
   - Branch: `main` / `/ (root)`
   - Click **Save**

Within 1-2 minutes, your website will be live at:
👉 **`https://prothamsarker.github.io`**
