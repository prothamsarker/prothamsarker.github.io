Computer Networking & Systems

Routing Information Protocol (RIP) Simulation

GitHub Repository

An academic computer networking project exploring the mechanics and convergence of the Routing Information Protocol (RIP). Focuses on distance-vector routing algorithms, hop-count metrics calculation (Bellman-Ford algorithm), routing table updates, split-horizon mechanisms, and how neighboring routers exchange network topologies across TCP/IP subnetworks.

🌐 Distance-Vector Hop-count metric routing & dynamic topology updates.
🔄 Convergence Logic Route poisoning, hold-down timers, and loop prevention.
📡 Protocol Analysis Packet broadcast exploration across local network topologies.
